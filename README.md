# Msingi

An AI teaching co-pilot for Grade 10 teachers. See `SPEC.md` for the full
product/technical specification.

## Backend (this pass)

Implements the local AI pipeline: `FastAPI → AIService → LangChain → RAG
Retriever → Ollama (qwen3:4b)`, with curriculum grounding via Chroma and
local embeddings.

- `docs/RUNNING.md` — install, configure, run, test
- `docs/OLLAMA-SETUP.md` — Ollama + qwen3:4b setup
- `docs/RAG.md` — curriculum ingestion and retrieval
- `docs/AI-ARCHITECTURE.md` — AI service / prompt / provider design

## Layout

```
backend/app/
  rag/       curriculum loading, chunking, embeddings, Chroma, retriever
  ai/        Ollama integration, prompt construction, AIService
  api/       FastAPI routes, schemas, reference data
  database/  SQLite models (Conversation, Message)
  core/      configuration (env vars)
curriculum/
  raw/           source PDFs/txt/md (commit these)
  vectorstore/   generated by ingestion (not committed)
scripts/ingest_curriculum.py   rebuild the vector store
tests/     rag/, ai/, api/
```
